# Word Search Crossword Solver (C++)

This project is a C++ console application designed to solve word search puzzles (crosswords) by scanning an input character matrix for words listed in a provided dictionary. It scans the grid in all directions: horizontally, vertically, and diagonally.

## Features
* **File I/O Modules:** Reads the crossword grid and dictionary list from text files; generates a results file.
* **Multi-directional Search:** Finds words horizontally (left-to-right), vertically (top-to-bottom), and diagonally (both top-left to bottom-right and bottom-left to top-right).
* **Masked Output Generation:** Generates a solved crossword map where unfound/garbage letters are masked out with asterisks (`*`).
* **Word Counter:** Keeps track of and prints the exact number of words successfully found in the puzzle.

## File Structure
* `input.txt` — The initial crossword grid composed of uppercase characters.
* `dictionary.txt` — The dictionary text file containing a list of target words to find.
* `output.txt` — The output file automatically generated by the program containing the masked crossword solution and the total found words count.

## Output Example

If `input.txt` contains a valid grid, the generated `answer.txt` will look like this:
```text
S  *   *   *  C
 *  O  *  *  A
 *  *   N   *  T
 *   *   *   *   *
 D  O  G  *  *

Total words found: 3
```

## How to Build and Run
1. Make sure you have a C++ compiler installed (like GCC/MinGW).
2. Place `input.txt` and `dictionary.txt` into the same folder as the source code.
3. Compile the application via terminal:
   ```bash
   g++ main.cpp -o crossword_solver
   ```
4. Run the executable file.
